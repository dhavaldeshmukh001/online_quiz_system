Jinja2 / Flask Template Syntax Used

This project uses Jinja2 template syntax for dynamic HTML pages and template inheritance.

Examples:

- "{% extends "base.html" %}" — inherits the base template
- "{% block title %}...{% endblock %}" — defines the page title
- "{% block content %}...{% endblock %}" — defines page-specific content
- "{{ variable }}" — displays dynamic data
- "{% if ... %}" — conditional rendering
- "{% for ... %}" — looping through dynamic data
